# AgroCarbon Intelligence

**Farmer-to-Carbon Tracker**: follows cotton stalk waste from the farmer to the processing unit, through biochar production and carbon storage, and calculates what each farmer should be paid.

> All figures shown in the screenshots are demonstration data, not verified carbon removal.

![Dashboard](assests/Screenshot%202026-11-24%20150129.png)

## Questions It Answers

1. Which farmers have cotton stalk waste?
2. How many tonnes can each farmer supply?
3. Which village should the collection vehicle visit first?
4. How much biomass has actually reached the processing unit?
5. How much biochar was produced?
6. How much carbon is stored in that biochar?
7. How much money should be paid to each farmer?

## Features

1. Register farmers
2. Save village and GPS locations
3. Record available cotton stalk quantity
4. Calculate estimated collection cost
5. Recommend the best collection route
6. Record actual weight received at the factory
7. Record biochar produced
8. Calculate estimated carbon stored
9. Generate farmer payment and production reports

## Tech Stack

### Backend and Database
- **Language:** Python 3
- **Framework:** FastAPI (REST APIs)
- **ASGI server:** Uvicorn
- **Database:** SQLite 3 with Write-Ahead Logging (WAL) and optimized indexes, built to scale to 1000+ records
- **Validation:** Pydantic for strict typing of API requests

### Frontend
- **Languages:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Architecture:** SPA-style routing via static HTML files
- **Styling:** Custom CSS (CSS Grid, Flexbox and animations; no Bootstrap or Tailwind)
- **API communication:** Fetch API (async GET, POST and PATCH)

### Core Logic
- Automated calculation engines for biomass yield, carbon sequestration and financial payouts
- Custom route optimization algorithm
- Client-side CSV generation and download

### Tools
- Git and GitHub
- Swagger UI (auto-generated by FastAPI)
- VS Code and Windows PowerShell

## Business Logic

| Calculation | Rule |
|---|---|
| Farmer payment | ₹800 × actual delivered tonnes |
| Route priority score | (tonnes × 10) − estimated collection cost |
| Biochar output | About 30% of biomass processed |
| Carbon stored | About 70% of biochar produced |

## Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

# 2. Install dependencies
pip install fastapi uvicorn pydantic

# 3. Run the server (replace "main" with your app's module name)
uvicorn main:app --reload
```

- Web app: `http://127.0.0.1:8000`
- Swagger UI (API docs): `http://127.0.0.1:8000/docs`
